      How do I get this file?
      

        
Option 1 — official web tool (no install needed): go to fonttools.github.io/fontspector, drop your font, run the analysis in your browser.

        
Option 2 — command line, if Fontspector is installed:

        
fontspector --profile googlefonts --json report.json MyFont.ttf

        
Then import the resulting report.json file above.
